# UL Spacetime

This repository contains the data and R code used to examine the spatial and
temporal dynamics of soil-associated bacteria in a temperate reservoir. The
project asks what happens to microorganisms associated with terrestrial soils
after they enter an aquatic ecosystem: whether they remain detectable, become
metabolically active, recur seasonally, or appear only transiently.

## Study design

The study combines two complementary datasets:

- A spatial transect extending from surrounding soils into the reservoir, with
  DNA and RNA samples used to characterize microbial presence and activity.
- A 2.5-year time series from the central reservoir, with paired DNA and RNA
  observations used to evaluate longer-term occurrence and activity dynamics.


## Analysis overview

The analysis:

1. Identifies OTUs detected in the sampled soils and reservoir.
2. Tracks soil-associated OTUs through the reservoir transect and time series.
3. Classifies RNA-based temporal dynamics as persistent, seasonal, transient,
   or unpatterned.
4. Compares how frequently taxa in each class are common when detected.
5. Quantifies the abundance and effective number of activity classes in the
   active reservoir community through time.
6. Compares maximum relative abundance in soil with maximum DNA- and RNA-based
   relative abundance in the reservoir transect and time series.

The classifications are operational descriptions of the observed time series.
In particular, “soil-associated” means detected in the soils sampled here and
does not imply that a taxon occurs exclusively in terrestrial environments.

## Repository contents

- `ul_spacetime_analysis.Rmd`: primary analysis and figure generation.
- `data/`: OTU tables, taxonomy, sample metadata, and environmental data.
- `bin/`: helper functions used by the analysis.
- `figures/`: figures generated by the analysis.

## Reproducing the analysis

Run or knit `ul_spacetime_analysis.Rmd` from the repository root. The workflow
reads its inputs from `data/` and writes graphical outputs to `figures/`.

The analysis uses R and packages from the tidyverse ecosystem, along with
`vegan`, `nlme`, `glmmTMB`, `emmeans`, and several plotting packages. A fixed
random seed is used for rarefaction so that results are reproducible across
runs using the same data and package versions.
